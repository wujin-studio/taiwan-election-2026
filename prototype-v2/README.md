# Election Atlas V2 Prototype

This is a separate design-validation prototype. The public index.html is intentionally unchanged.

Design direction: warm ivory editorial UI, coral and violet highlights, real county TopoJSON, 3D-like extruded county geometry, camera focus, no full-page scroll, in-context drawer.

Data source: https://github.com/dkaoster/taiwan-atlas (counties-10t.json, COUNTYCODE/COUTYNAME).
Validation criteria:
1. Six actual metro shapes and county borders render.
2. Selected metro extrudes, zooms, and opens city panel.
3. Mobile bottom sheet never navigates away.
4. Missing research data is labeled, never invented.
5. Do not promote to production without screenshots on phone and desktop.
